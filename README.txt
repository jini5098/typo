타이포 스튜디오 3.2.0 — GitHub Pages 올리는 방법

1. 이 폴더의 파일을 모두 GitHub 저장소 맨 위(루트)에 올려요.
   index.html, manifest.webmanifest, sw.js, icons 폴더
2. 저장소 Settings → Pages → Branch: main / (root) → Save
3. 1~2분 뒤 https://아이디.github.io/저장소이름/ 으로 열려요.
4. 크롬·엣지에서 열면 홈 화면 오른쪽 위에 "앱 설치" 버튼이 생겨요.
   (휴대폰은 브라우저 메뉴 → 홈 화면에 추가)

Supabase SQL은 setup → v2 → v3 → v4 순서로 한 번씩 실행해요 (이미 실행한 건 건너뛰어도 돼요).
